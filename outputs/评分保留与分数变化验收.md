# 评分保留与分数变化验收

2026-09-23，本地代码与独立测试数据验证。正式上线结果见文末。

- 学生提交新材料后，排队、评分中、失败或需要补拍时，继续显示本环节最近一次已完成的得分，明确标注“保留上次得分”。首次提交尚未完成评分时仍显示待评分。
- 新评分完成后自动替换当前得分及评价；分数升高或降低均以最新完成的提交版本为准。教师概览、累计积分、详情与成果投屏使用相同规则。
- “分数变化”按提交顺序列出历次得分及满分，教师复核标明来源，不在该区域重复旧评语。刷新、重新登录后仍可读取后台保存的分数。
- 原始版本与评价记录不删除。旧任务成绩单独标记，不计入新任务积分；评分未完成不会记为 0 分，教师确认的 0 分正常保留。
