## 测试中修复的问题与边界

首次仅替换模型名时，出现普通文本代替 JSON 的回复。启用普通 JSON 模式后，又发现评分字段不符合程序要求，因此改为明确的 JSON Schema。

旧的 2000 token 额度曾全部用于推理，评分内容为空；增加额度并设置低推理强度后，最终测试没有截断。较早测试曾出现 69 秒的单次对话，延迟仍取决于服务商负载和路由。

这些结果说明接口与课堂流程在所测样例中可用，不代表评分完全准确或回复始终只问一个问题。真实学生手写照片、教室网络和现场使用体验仍需课堂验证。Latest 别名会自动更新底层模型，未来表现可能变化。
