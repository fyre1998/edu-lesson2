# 两环节生长素课堂验收

2026年9月20日，本地实现并验收 `flow_version=3`。未发布生产环境，未自动归档或转换已有课次，原 Word 与 PPT 未修改。

## 已实现

- 第一部分从教师提供的六张原图中匹配结果，支持文字、照片、多处理、多次提交；不计分。第五类按明胶处理，第六张整体展示。
- 第二部分仅开放中性的琼脂收集操作图。实验处理40分、有效对照30分、条件可比10分、观察与预测20分；中央放置不能获得偏放20分，不因缺少样本量、重复次数、时长扣分。
- 匹配结果和评价绑定各次提交。学生与教师可回看历史；旧请求迟到不覆盖新版本；图片不能辨认时请求补充，不形成0分成绩。
- 新版不使用随机分图和旧版历史结果开放按钮。八组、拍照、语音、教师修分、双组投屏和旧课次保留。
- 教师原图接口限制本组与教师访问，未匹配图不能通过猜测地址读取。完整温特结果图不作为新版教学素材下发。

## 真实模型与浏览器验收

在独立的 `work/classroom-preview-8013/` 数据库中创建测试课次，使用现有AI配置，未使用正式课堂数据。

| 样例 | 实际结果 |
|---|---|
| 六类明确的实验处理 | 均返回对应教师原图 |
| 一次提交明胶隔层和向光侧云母两种处理 | 返回两张对应图 |
| 插入云母但未说明范围 | 初测误判为全隔断；补充边界规则后复测转为追问，不返回图片 |
| 只写尖端下方插入明胶 | 追问具体范围和方式 |
| 明确黑暗条件的云母隔断 | 不套用单侧光图片，提示无对应图 |
| 未覆盖的盐水处理 | 提示暂无对应图 |
| 繁体中文表达向光侧云母 | 正确匹配 |
| 完整偏放方案，无具体样本量、时长 | 100分；首次评分未完成，学生按钮重试后恢复，无需重复提交 |
| 只有中央放置，其余完整 | 80分，偏放项未得分 |
| 明确不设对照 | 60分，对照与可比条件未得分 |
| 明确保留尖端在琼脂上 | 90分，移去尖端项未得分 |
| 仅上传完整设计的文字照片 | 100分 |
| 仅上传明胶隔层思路的文字照片 | 正确匹配原图 |
| 仅上传空白照片 | 提示补充清晰内容，无正式成绩 |

照片测试使用人工生成的文字图片和空白图片，验证视觉输入链路；不等同于真实手写识别准确率验收。原始测试记录位于本地 `work/two-part-real-acceptance.json`。

浏览器已查看学生两环节导航、提交多图、评分及重试、中性收集操作图、教师八组概览、两部分的双组投屏。布局可读，参考图片保持比例，长内容可独立滚动。摄像头和语音保持已有代码并通过自动回归；未在本次验收中调用真实设备录音或拍摄。

## 使用与边界

本地预览地址：<http://127.0.0.1:8013/classroom/>，邀请码 `BIO-PREVIEW`。重启命令：

```powershell
.venv\Scripts\python.exe scripts/start_classroom_preview.py --port 8013
```

预览只监听本机，包含明确标记的验收课次。新版本需通过现有生产部署流程发布后，才会在正式网站创建的新课次中使用。已有旧课次不会自动转换。

真实模型仍可能误读复杂手写或非典型表述，教师可查看学生原文、参考图和评分依据，并对成绩复核。页面提供失败重试和不清晰内容补充流程。
